CPQ-lite: configure, price, quote

Quote revisions, price lists, discount authority, PDF quotes, quote-to-order.

Problem

Sales teams send quotes from spreadsheets, approve discounts by chat, and re-key accepted quotes into the order system.

Architecture

Request flow

Sales UI
quote-service
pricing-service
approval workflow
PDF
OMS

Learning outcomes

  • Immutable revisions
  • Pricing procedures
  • Approval matrices
  • Document generation
  • Idempotent conversion

MVP

  • Quotes with lines, price lists and customer-specific prices
  • Discount authority: >15% manager, >25% director
  • Validity dates enforced
  • PDF quote generation
  • Accept → sales order in OMS (idempotent on quote id + revision)

Stretch

  • Product configuration rules (compatible options)
  • E-signature port
  • Win/loss analytics

Services

ServiceResponsibility
quote-serviceQuotes and revisions
pricing-servicePrice lists, conditions, promotions
document-servicePDF rendering

Entities

EntityFields
Quotenumber, revision, customer, lines[], totals, validUntil, status
PriceListid, currency, entries[]
DiscountApprovalquoteId, revision, level, approver

APIs

EndpointPurpose

POST /quotes/{no}/acceptConvert to order
GET /quotes/{no}/pdfDocument

Topic / eventMeaning

Non-functional requirements

  • Money as decimal with currency; never floating point
  • Accepted revision immutable

Testing

  • Pricing table tests including the Q10045 example (total $2,480)

Plan

  • W1: quotes and pricing
  • W2: approvals
  • W3: PDF and conversion
  • W4: UI and demo

Portfolio deliverables

  • Pricing procedure document
