Advanced warehousing: slotting, labour, cycle counts, lot tracking and recalls

Beginner lens. Popular items close, count often, know where every batch went.

Beyond pick and pack, good warehouses slot fast movers well, manage labour against engineered standards, count continuously, track lots and serial numbers for recalls, keep cold chain intact and perform value-added services such as kitting.

In plain words

Put the most popular items closest to packing, count a few shelves every day instead of closing for a stock-take, and know exactly which customers got a bad batch so you can recall only those.

Architecture

Traceability requires lot/serial on every movement event. Without it, a recall becomes "recall everything".

  • Capture lots at receipt via GS1-128 barcodes
  • Store genealogy: supplier lot → production lot → shipments
  • Slotting is periodic optimisation, not real-time

What can go wrong

Failure scenarioHow to handle it
Recall too broadNo lot data; recall all stock.
Expired stock shippedFIFO used instead of FEFO.
Labour standards ignoredProductivity unknown; staffing guesswork.
