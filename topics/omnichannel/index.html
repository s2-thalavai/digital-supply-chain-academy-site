Omnichannel: BOPIS, BORIS, ship-from-store and returns

Beginner lens. One stock picture, many ways to buy and return.

Omnichannel retail lets customers buy, collect and return across any channel. Buy online, pick up in store (BOPIS); buy online, return in store (BORIS); ship from store (stores act as mini-DCs). Unified commerce means one inventory, one order and one customer view behind all of it.

In plain words

You order shoes on the app, pick them up at your local store tonight, and next week return the wrong size at a different store. For that to work, every store and warehouse must share the same stock picture and the same order history.

Architecture

Omnichannel lives or dies on inventory accuracy in stores. Apply safety stock, fast inventory events, and lock order rows when computing returnable quantities.

  • Store inventory feeds through POS and adjustments in near real time
  • Return refund rules are policy data (reason × condition)
  • BORIS restocks into the returning store, not the original shipping node

What can go wrong

Failure scenarioHow to handle it
BOPIS order but shelf emptyShort pick in store; offer substitution, another store, or ship-to-store.
Return more than boughtGuard returnable quantity = fulfilled − already returned, with a row lock.
Refund fraudReceipt-less returns limits and serial number checks.
